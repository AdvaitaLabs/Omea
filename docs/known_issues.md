# 适配范围与历史结果

发布目录独立于原实验目录，旧数据和生成结果没有改写。本次整理保留各方法的权重、采样参数和原始尝试预算，统一命令入口和输出布局。

## 已修正的发布代码问题

Pfizer coupled diffusion 的适配器通过动态函数副本补充核心电荷保持，但副本持有单独的全局字典。随后设置的“非连接核心原子禁止连到 R 基”掩码原先只进入上游模块，没有进入这个副本。发布适配器同时绑定副本中的掩码；这是推理实现修正，新结果需要重新生成，不能据此改写历史指标。Flow 的调用路径未受这处绑定问题影响。

原 SDF 导出可能丢失芳香显式氢信息或把未指定双键立体标志写成 EITHERDOUBLE。发布格式先无损保存 RDKit 原始状态，再对分子副本导出 SDF，统一用未改变的三维坐标做立体化学审计。评分读取无损记录，不凭原配体猜测或修复生成分子。

## 仍需如实解释的限制

- 全分子重建可能改变核心的键、芳香性或形式电荷，即使采样时核心元素和坐标没动。统一审计会把这些输出记为失败。本 benchmark 不在采样后修复核心图。
- DiffDec 使用 10 个原子槽和 dummy 类型；NEAT 使用原生停止机制；LDDM 保留原生虚拟节点。它们未必能原生控制精确 R 基原子数，最终尺寸错误仍算失败。
- 某些方法有原生性质引导，某些没有。适配器使用的原生参数和修正见方法说明，不把它们当成同一个无引导采样器。
- 45 个案例来自公开 MOAD split 的派生任务；30 个主比较案例按已有共同支持条件预先固定。它们不是 DiffSBDD 论文原始子集，也没有证明与所有 checkpoint 的训练数据或同源蛋白无重叠。
- PoseBusters 内部能量检查可能因力场不支持而缺失。这表示没有完成统一几何验证；成功率中记为未通过，并单独报告，不等同于已经证明化学结构错误。
- 这次代码发布做了静态、CPU 控制和实际结构评分检查，没有用新入口重新跑完 13 个方法的全量 GPU 生成；依赖快照来自已有工作环境，未逐一从空环境重装。

## 周报版本的引导代码

`guidance/` 中的历史脚本保持原文，与原 benchmark 的同名模块分别保存。它们沿用实验目录和部分绝对路径，没有接入统一的工作目录环境变量，也没有通过本发布目录重新跑全量生成。16.50% 是原实验的统计结果；后续最终核心保持实验不在本版范围内。来源和边界见 [引导优化说明](guidance.md)。
